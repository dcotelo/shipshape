# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately — do not open a public issue.

- Email: **me@dcotelo.dev**
- Or use [GitHub private vulnerability reporting](https://github.com/dcotelo/shipshape/security/advisories/new) once enabled for this repository.

## Response timeframe

- **Acknowledgement:** within **7 days** of the report.
- **Initial assessment and severity triage:** within **14 days**.
- **Fix or public disclosure decision:** within **90 days**, coordinated with the reporter.

## Scope

This repository contains an agent prompt and YAML policy configuration; it ships no executable code. Reports about unsafe instructions in `AGENTS.md` (e.g., guidance that could cause an agent to leak secrets or destroy data) are in scope and treated as vulnerabilities.

## Disclosure

Confirmed vulnerabilities are published as GitHub Security Advisories on this repository after a fix is available.
